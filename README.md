# 🛡️ Laravel Face Recognition Authentication System

## 📌 About The Project
This repository contains my graduation project for my Information Technology & Computer Science degree. It is a secure, modern web application that replaces traditional password-based login with a **Biometric Facial Recognition System**.

Built on top of the **Laravel** framework, this project demonstrates the integration of backend MVC architecture with AI-driven face detection algorithms to provide a seamless and highly secure user authentication experience.

## 🚀 Key Features
* **Facial Recognition Login:** Secure access using live face scanning.
* **Laravel Middleware Security:** Deeply integrated access control and route protection.
* **RESTful API Integration:** Efficient communication between the backend and biometric models.
* **Database Management:** Well-structured relational databases using MySQL/PostgreSQL.
* **Clean UI:** Responsive and user-friendly interface.
